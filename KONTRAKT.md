## Arbetsflöde i Git
- Ingen pushar direkt till `main`. Allt går via egna brancher (`feature/<vad-du-gör>`) och pull requests.
- Minst en annan i gruppen granskar och godkänner innan merge.
- `mvn test` ska vara grönt innan en PR skickas.
- Små, tydliga commits med beskrivande meddelanden.

## Beslut
- Beslut tas gemensamt; vid oenighet gäller majoritet.
- Större ändringar (struktur, nya beroenden) stäms av med gruppen först.

## Konflikter
1. Ta upp problemet direkt och sakligt med den det gäller.
2. Löser det sig inte, ta upp det med hela gruppen.
3. Som sista steg kontaktas läraren.
